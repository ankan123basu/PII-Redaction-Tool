Design Tradeoffs

🗓️ DOB Context-Window Guard

Dates only classified as DOB if a keyword ("DOB", "date of birth", "born") appears within 80 characters. Avoids redacting hundreds of incorporation/filing dates — massive precision win at recall cost.

💳 Luhn Modulo 10 Checksum

Credit card regex matches that fail the Luhn checksum are rejected. The single biggest precision win — 16-digit account numbers and reference numbers in financial documents are correctly excluded.

🏢 ORG Stoplist Filtering

"the Company", "our Company", "the Board" excluded from COMPANY_NAME. Prevents dozens of false positives per page in legal prose where these appear hundreds of times as pronoun-references.

🔗 Levenshtein Fuzzy Merge

Near-duplicate names merged via RapidFuzz token_sort_ratio ≥ 85 (e.g., "Kushal Hegde" ↔ "Kushal Subbayya Hegde"). Risk: false merges. Mitigated by same-type-only matching.

🏛️ CIN as PII Policy

CIN (Corporate Identity Number) detection enabled by default. CINs are publicly registered with MCA — not secret — but uniquely identify companies. Users can disable via entity_rules.yaml.

Installation & Reproducibility

      
# Clone and install
git clone https://github.com/ankan123basu/PII-Redaction-Tool.git
cd PII-Redaction-Tool && pip install -e ".[dev]"
python -m spacy download en_core_web_lg

# Run 128 unit tests
python -m pytest --tb=short -q

# Run redaction pipeline
python -m pii_redactor redact \
  --input "data/input/Red Herring Prospectus.docx" \
  --output "data/output/redacted_output.docx" \
  --entity-map-out "data/output/entity_map.json" \
  --report "data/output/redaction_run_report.json"

# Run evaluation
python -m pii_redactor evaluate \
  --predictions tests/fixtures/real_predictions_expanded_flat.jsonl \
  --ground-truth tests/fixtures/real_ground_truth_expanded_flat.jsonl \
  --output EVALUATION_REPORT.md
